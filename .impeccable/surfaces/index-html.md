## Scope

The main page of phplives.dev, plus the archive page. Mode: Experience, where the
entries lead from the first viewport. Visitor: a PHP developer who wants one link
that proves PHP is alive. Job: see in five seconds that the list is real and recent,
then share it.

## Direction contract

THESIS: Every project is a parcel that shipped, and its postmark is the date proof.
It refuses the showcase grid of logo cards and the awesome-list link dump.

OWN-WORLD: Prussian ink blue (#12285a), chosen 16/10/2026 over the first depot green, which read too close to Starbucks and Jameson. Since decision 8 (16/10/2026), the light theme sets Prussian ink on a pale blue-grey field (#e6eaf2), and the dark theme uses a deep Prussian field (#0d1d42). The /dev/null band stays Prussian in both. Thermal-white 4x6 labels with heavy
black print rules, a big inverse routing code per stack (LRV, SYM, NTV, PHP), one ring
postmark in the same blue ink per label, a barcode and a TRACK line that is the source link.
Signal orange is law: it marks only the newest parcel (its strip, its postmark and its
NEWEST tag in the list). Archivo across widths. JetBrains Mono only for data: dates,
tracking numbers, counts and the terminal command.

STORY: The visitor reads the line, sees a manifest slip with the count and the last
ship date, then scans labels: who, what, when, where to check. They follow a TRACK
link or share the page. Makers learn they can commit their own on /dev/null.

FIRST VIEWPORT: The theme's field. Top bar: wordmark left; Manifest, Archive and
"Commit it on /dev/null" links; the Light / Dark / System toggle right. Left: `PHP
delivers. PHP lives!` at display size. Right: a white manifest slip (parcels, shipped
since, last shipped, stacks). The first row of labels starts inside the fold.

FORM: Shipping Manifest, candidate 1 on the ordered list (the user's pick over the
assigned candidate 6, Arrivals Board). Seed key 5fa8f0fa. Archive is a dense manifest
sheet, one row per parcel. The main page can show the same sheet through a Labels /
List toggle, with a stack filter (decision 10). Signature: labels print in once on load, then each
postmark stamps.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
